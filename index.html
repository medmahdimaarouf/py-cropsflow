Introduction

CropsFlow is designed for engineers who need a structured way to create automation systems using reusable components, dependency-driven initialization, workflows, and service orchestration.

Why CropsFlow?

  • ✓ Modular composition for large automation systems
  • ✓ Dependency injection for clean service wiring
  • ✓ Reusable actions, pipes, and task templates
  • ✓ Scheduling and periodic job execution
  • ✓ Event-driven infrastructure
  • ✓ FastAPI router integration

Core developer workflow

  • ✓ Declare services with decorators
  • ✓ Scan dependencies and bootstrap modules
  • ✓ Build actions and task pipelines
  • ✓ Schedule jobs and orchestrate tasks
  • ✓ Expose APIs with router integrations
  • ✓ Connect events and automation workers

Architecture

The framework is structured around runtime composition, dependency resolution, and automation workers.

Core components

  • ✓ Application – bootstraps the framework and resolves dependencies
  • ✓ Container / Injector – manages service lifecycle and resolution
  • ✓ Common Module – exposes shared actions and pipes
  • ✓ Scheduler – runs recurring and delayed tasks
  • ✓ Router – handles HTTP APIs and structured responses
  • ✓ Orchestrator – manages task workers and job flows

Typical app lifecycle

  • ✓ Define services, actions, pipes, and modules
  • ✓ Register and scan metadata at runtime
  • ✓ Resolve dependencies and initialize modules
  • ✓ Run scheduled jobs or workers
  • ✓ Expose routes and handle responses
  • ✓ Publish or consume events as needed

Examples

Common patterns used throughout the framework.

Service example

from cropsflow.common import service, InjectionScope

@service(scope=InjectionScope.DEFAULT)
class Driver:
    def __init__(self):
        pass

Action example

from cropsflow.common import action, option, inject
from cropsflow.common.abstracts import Action

@action(selector='my-pipe')
@option(key='my-option', meta_type=str)
class MyAction(Action):
    @inject(arg_name='driver', token=Driver)
    def __init__(self, driver: Driver):
        self.driver = driver

    def start(self, context, options={}):
        return {"status": "ok"}

Usage

Build reusable modules, initialize your app, schedule work, and expose services through routing.

import asyncio
from cropsflow.core.application import Application

async def main():
    app = Application()
    # await app.bootstrap(module=AppModule)
    print("Application initialized")

asyncio.run(main())

Scheduling

from cropsflow.scheduler import BackgroundScheduler

scheduler = BackgroundScheduler()

@scheduler.every(seconds=10)
def check_status():
    print("Running every 10 seconds")

Router

from cropsflow.router import Router
from fastapi import FastAPI

app = FastAPI()
router = Router(prefix="/api")

@router.get("/health")
async def health():
    return Router.success({"status": "ok"})
